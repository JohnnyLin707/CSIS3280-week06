老师代码风格速记（写答案时照这个来，判卷更稳）

  • 类文件注释骨架：// property → // magic method → // getter and setter → // custom methods
  • 构造方法里调用 setter 赋值，校验逻辑只写一份
  • 子类要读父类属性 → protected；复用父类逻辑 → parent::
  • 脚本第一行：require_once '../src/Xxx.php';，先父类后子类
  • 输出用 print，调试用 var_dump
  • 双引号插值 "{$this->name}"；字符串拼接用 .、累加用 .=
